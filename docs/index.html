Spark⚡Plug

場に火をつけろ。

発表者と参加者の間に流れる情報を可視化・拡張・保存する、コミュニティイベント向けのリアルタイム盛り上げ + 振り返りアプリ。参加者はQRを読むだけ、アプリのインストール不要。

GitHub で見る → 主催者マニュアル 📖

Spark plug = 点火プラグ。エンジンをかける。場に火をつける。

3 Pillars

盛り上げて、拾い上げて、振り返る。

イベントの「その瞬間」だけで終わらせない。会場の熱をリアルタイムに増幅しながら、あとから資産になるログとして残します。

🔥

盛り上げ

ニコニコ風コメント流し（AA対応）、リアクション爆発、効果音（ドン・カッ・拍手）、会場スクリーン演出。発表中の空気を全員で作る。

🎤

拾い上げ

選択式アンケートのリアルタイム集計、参加者からの質問、いいねによる優先度づけ。声の大きい人だけじゃない、全員の声を拾う。

📊

振り返り

全ログをCSVエクスポート（Excel対応）。Claude や ChatGPT に投げれば、盛り上がりのタイムラインや質問の傾向をAIが分析。

Features

本番で使える機能、ぜんぶ入り。

💬

コメント流し

横流れ ⇄ 下から上をホストが切替。匿名/記名どちらもOK。

🎨

AAコメント

複数行アスキーアートを等幅・改行保持でゆっくり流す。キタ━━━!!

🔊

効果音

ドン/カッ/拍手。Web Audio API 合成フォールバック付き。

📊

アンケート

ホストが作成・締切。投票し直し可、スクリーンにライブ集計。

📈

エモメーター

発表者ビューに会場の熱量を波形＋バイブで伝える。

🙋

質問トリアージ

いいね順で「今答える/後で/後日」に振り分け、スクリーンにピン留め。

🖥️

画面共有

発表スライドを会場スクリーンの背景に取り込み、演出をその上に重ねる。

📥

CSVエクスポート

UTF-8 BOM・Excel対応。イベント終了時にワンクリックで回収。

4 Views

役割ごとに最適化された4つの画面。

同じイベントIDを開くだけ。参加者と会場スクリーンはURLひとつ、ホストと発表者は権限トークン付きリンクで乗っ取りを防止。

AUDIENCE

📱 参加者

QRコードを読んでブラウザで即参加。コメント・リアクション・投票・質問。

/e/{eventId}
SCREEN

🖥️ 会場スクリーン

コメントと演出が流れるメイン画面。QR表示・効果音もここから。

/e/{eventId}/screen
PRESENTER

🎤 発表者

エモメーターで熱量を感じながら、質問を手元で確認。

/e/{eventId}/presenter?t=…
HOST

🎛️ ホスト

アンケート作成・質問トリアージ・演出切替・CSVエクスポート。

/e/{eventId}/host?t=…
Ops & Cost

身軽に運用、財布に優しく。

1 コンテナ

Express + Socket.IO がビルド済み React SPA を同一オリジン配信。CORS 不要のシンプル構成で Azure Container Apps にデプロイ。

¥0 / 待機時

scale-to-zero でアクセスが無ければ実行コストゼロ。定常コストはコンテナレジストリの約 $5/月 のみ。

数十円〜 / イベント日

当日だけ min replica 1 に上げて数十〜数百円。終わったらCSVを回収してまた眠らせる。
